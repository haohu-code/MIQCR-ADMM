# Linux build used for the MIQCR-CB comparison

The comparison uses GCC 12.3.0 and OpenBLAS 0.3.25. Build in a separate
copy of the bundled dependency. The commands below select optimized builds
without editing the third-party optimization sources.

Set `MIQCR_RELEASE` to the absolute `release_code` directory, `MIQCR_BUILD`
to a new absolute build directory, and `OPENBLAS_ROOT` to your OpenBLAS
installation. These commands were tested on x86-64 Linux.

```sh
mkdir -p "$MIQCR_BUILD/external" "$MIQCR_BUILD/lib"
cp -R "$MIQCR_RELEASE/external/MIQCR-CB" "$MIQCR_BUILD/external/MIQCR-CB"
ln -s "$OPENBLAS_ROOT/lib/libopenblas.so" "$MIQCR_BUILD/lib/libblas.so"
ln -s "$OPENBLAS_ROOT/lib/libopenblas.so" "$MIQCR_BUILD/lib/liblapack.so"
export LIBRARY_PATH="$MIQCR_BUILD/lib:${LIBRARY_PATH:-}"
export LD_LIBRARY_PATH="$MIQCR_BUILD/lib:${LD_LIBRARY_PATH:-}"
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
cd "$MIQCR_BUILD/external/MIQCR-CB/source/Smiqp-1.0"
./configure --disable-shared \
  --with-blas="-L$OPENBLAS_ROOT/lib -lopenblas" \
  --with-lapack="-L$OPENBLAS_ROOT/lib -lopenblas" \
  CFLAGS='-O2 -fcommon' CXXFLAGS='-O2 -std=gnu++11'
# Use the complete libtool script generated by the bundled Ipopt configure.
cp Ipopt/libtool libtool
bash libtool --version
make -C Csdp/lib clean
make -C ConicBundle clean
make -C Csdp/lib -j4 CC=gcc \
  CFLAGS='-m64 -O3 -fcommon -ansi -Wall -DBIT64 -DUSESIGTERM -DUSEGETTIME -I../include'
mkdir -p ConicBundle/OPTI.linux.x86_64.g++
make -j4 CC=gcc MODE=OPTI
export MIQCR_EXTERNAL="$MIQCR_BUILD/external"
```

The separate CSDP build preserves its required ABI definitions and uses
`-O3` without fast-math assumptions. `MODE=OPTI` selects ConicBundle's
supplied `-O3 -DNDEBUG` build instead of its `DEBU` default. The libtool
copy addresses the truncated top-level script observed with this source
package; it changes a generated build file, not optimization code.

Set `MIQCR_EXTERNAL` in the environment used to start MATLAB. The runner
then finds `MIQCR-CB/source/Smiqp-1.0/src/Alg/smiqp` below it. A licensed
Gurobi MATLAB interface is also required for Phase 2 and direct Gurobi;
the current experiment uses Gurobi 13.0.2. See [EXPERIMENTS.md](EXPERIMENTS.md)
for the numerical protocol. Other platforms or compiler versions require
their own build and numerical checks.
